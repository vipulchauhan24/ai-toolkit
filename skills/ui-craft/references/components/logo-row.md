# Logo row

**Use for** real customers, partners or tools, with permission.

- Logos in one colour (`--ink-2` or `--ink-3`), unless the full-colour logo is the point.
- Optical sizing: match visual weight, not height. Around 20 to 32px tall.
- Gap `--space-10` to `--space-12`. Wraps, or scrolls slowly.
- A short plain label if needed.
- Each logo has alternative text with the company's name.

Tech stack logos come from Tabler (`icon.md`). If one is missing, write the name as text. Do not draw a substitute.

**Avoid:** fake logos. Logos for companies that haven't agreed. Using a logo row as filler.
