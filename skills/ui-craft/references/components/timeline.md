# Timeline

**Use for** real sequences: work history, project stages, a schedule.

- A left column for dates, `--text-sm` in `--ink-2`, about 120 to 160px wide from 768px.
- Content on the right. Entry gap `--space-8` to `--space-12`.
- A 1px `--line` vertical rule with small markers is optional.
- Use a list element. Order newest first for a career, in sequence for a process.

**Phone:** dates sit above each entry.

**Avoid:** alternating left and right on the page. Timelines for things that have no order.
