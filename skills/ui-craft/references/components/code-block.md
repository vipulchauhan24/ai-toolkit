# Code block

- `--font-mono`, `--text-sm`, line height 1.6.
- Padding `--space-4`, `--radius-md`, `--surface-2` background.
- Scrolls sideways inside itself. The page must not.
- Syntax colours pass 4.5:1 in both themes.
- A copy button at the top right, at least 24px, with a visible confirmation.
- A filename or language label if it helps.
- Inline code: `--font-mono`, 0.9em, `--surface-2`, small padding.

Code must be real and work. Long lines don't wrap by default.

**Avoid:** fake terminal windows with traffic lights for decoration.
