# Link

**Use for** going somewhere.

- Inside text, always underlined. `text-underline-offset: 0.2em`.
- Colour `--ink` with an underline, or `--accent` if it passes 4.5:1.
- Navigation links may drop the underline, because their position shows what they are.
- External links open in the same tab unless the user would lose work. If a new tab opens, say so with text or an icon.
- Inside text the size follows the surrounding text. Standalone links on touch screens have a tap area of at least `--touch`.

**Hover:** the underline changes or draws in. **Focus:** the standard ring.

**Avoid:** a colour change as the only sign of a link in text. "Click here".
