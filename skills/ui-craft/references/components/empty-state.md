# Empty state

Shown when there is nothing to show. Keeps the frame of the block it replaces.

- Centred within the block, `--space-10` to `--space-16` vertical padding.
- Heading `--text-base` weight 500, explanation `--text-sm` in `--ink-2`.
- One clear action.
- A small icon is optional. No big illustration in dense apps.

Words: see `../copy/copy.md` section 10. Say why it's empty, what appears here and how.

Inside a table or list, span the full width.

**Avoid:** "No data". Showing this while data is still loading.
