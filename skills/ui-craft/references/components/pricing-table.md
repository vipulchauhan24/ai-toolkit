# Pricing table

**Use for** comparing two to four plans.

| Part | Value |
|---|---|
| Plan name | `--text-h3` |
| Who it's for | `--text-sm` in `--ink-2`, one line |
| Price | `--text-h2`, tabular figures, with the unit right beside it |
| Button | Medium or large, same position on every plan |
| Features | `--text-sm`, list with check icons, in the same order in each plan |

- Features line up across plans. Show what changes, and do not repeat what doesn't.
- Mark a recommended plan only if it really is one, with more than colour.
- Monthly and yearly switch: state the actual saving.
- For long comparisons, add a full table under the cards, using `table.md`.

**Phone:** stacked, with the recommended plan first or clearly marked.

**Avoid:** hidden fees. Crossed-out prices that were never charged. Plan names that mean nothing.
