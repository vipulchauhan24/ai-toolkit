# Avatar

- Sizes: 24, 32, 40, 48 or 64px.
- Circle for people, `--radius-md` for companies and products.
- Real photo, or initials on `--surface-2`.
- Alt text is the person's name, or empty if the name is right beside it.
- In a group: overlap by about a quarter, with a 2px `--bg` ring, and "+3" past four.

**Avoid:** invented portraits. Random colours per user in a marketing page.
