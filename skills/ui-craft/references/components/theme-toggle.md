# Theme toggle

- An icon button, `--control-md`, with an `aria-label` that says what it does.
- Default to the system preference. Remember the choice after the user makes one.
- Set the theme before the first paint to avoid a flash, using a small inline script in the head.
- Icons from Tabler: `sun` and `moon`.

Include one only if the project has both themes. Place it in the nav or footer.

**Avoid:** a large labelled pill as the most visible thing in the nav.
