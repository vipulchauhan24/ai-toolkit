# Hero

**Job:** say what this is, for whom, and what to do next. Its main message and button are visible without scrolling at 1440x900 and 390x844.

| Variant | Use when | Build |
|---|---|---|
| `split` | There is text and one strong image or product shot | 5 + 7 columns, vertically centred |
| `centered` | One short message and nothing to balance it | `--container-narrow`, centred text, one action |
| `proof-panel` | Few images but strong numbers: portfolios, technical products | Text left, a panel of real stats or facts right |
| `product-frame` | Software with a real interface to show | Text above, large product screen below, cropped by the fold |
| `statement` | One strong sentence carries the page | `--text-display`, plenty of space, one small action |
| `media-full` | A very good photograph or video | Full-bleed image, text on a scrim, docked to one edge |
| `name-led` | A personal site or a brand with a short name | Name set very large, one-line description |
| `info-first` | A place or event | What, where, when in the first screen, then photo |

**Sizes:** headline `--text-h1`, or `--text-display` for `statement` and `name-led`. Supporting line `--text-lead` in `--ink-2`, up to `--prose`. Headline to supporting line `--space-4` to `--space-6`. Supporting line to buttons `--space-8`. Top padding `--space-16` to `--space-24`.

**Content:** h1, sub, one or two buttons. See the kind's copy file.

**Phone:** one column. Text first, unless the image is the message. Buttons may go full width.

**Avoid:** a centred heading, pill badge and two buttons above a screenshot as an automatic choice. Gradient blobs. A headline below the fold.
