# Product detail

**Job:** answer everything before the till.

**Layout from 1024px:** images 7 columns, details 5, with details sticky. On phones the image comes first, then name, price and button.

**Order in the details column:** name, price, short description, variants, button, delivery and returns. Below: specs table, longer description, reviews.

Variant choices change the image. Images use one aspect ratio, and a real view of each thing promised.

The button stays reachable on phones: a sticky bar is fine if it covers nothing.

Words come from `COPY.md`.
