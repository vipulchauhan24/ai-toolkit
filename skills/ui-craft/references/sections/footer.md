# Footer

**Job:** practical facts, and a sensible end to the page.

| Variant | Use when |
|---|---|
| `minimal` | One row: name, year, a few links. Most small sites |
| `columns` | A real site map of many pages |
| `visit` | A place: address, hours, contact |
| `large-name` | A name-led site, closing with the name at full width |

Component details in `../components/footer.md`.

**Avoid:** padding a footer to fill a screen. Columns of empty links.
