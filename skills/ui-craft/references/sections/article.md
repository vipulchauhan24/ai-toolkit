# Article

**Job:** make reading comfortable.

**Layout:** title, standfirst, author and date, then body in `--prose`. Body 16 to 18px with `--leading-normal`. Images may run to `--container-narrow`.

| Element | Spacing |
|---|---|
| Paragraph to paragraph | `--space-5` |
| Above h2 | `--space-12` |
| Above h3 | `--space-8` |
| Heading to its text | `--space-3` |
| Around images and code | `--space-8` |

A table of contents helps on long pieces: sticky to one side from 1280px, collapsed at the top on phones.

Code uses `../components/code-block.md`.

**Avoid:** drop caps, pop-ups and sticky bars while reading.
