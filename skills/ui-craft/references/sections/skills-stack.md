# Skills and stack

**Job:** a quick fit check.

| Variant | Use when |
|---|---|
| `grouped-list` | Labelled groups with comma-separated names: the plainest and often best |
| `icon-grid` | Tabler brand icons with names, for a technical audience |
| `inline` | A short list folded into the about text |

Only what you would happily be interviewed on. Names missing from Tabler stay as text.

**Avoid:** skill bars and percentages. A large empty panel with a few logos in it.
