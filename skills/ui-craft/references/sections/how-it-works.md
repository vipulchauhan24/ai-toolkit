# How it works

**Job:** show the steps, so it feels easy and real.

| Variant | Use when |
|---|---|
| `steps-row` | Three or four short steps |
| `steps-list` | Steps that need explaining, with one image each |
| `single-image` | A diagram or one annotated screen says it all |

Numbers are fine here, because the order is the point. Each step starts with a verb.

**Leave out** if the order doesn't matter.

**Phone:** a vertical list.

**Avoid:** invented steps, to make a simple thing seem complex.
