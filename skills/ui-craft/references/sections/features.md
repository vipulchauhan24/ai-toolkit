# Features

**Job:** show what it does, led by what the user gets.

| Variant | Use when |
|---|---|
| `list` | Few features explained well: text in rows, heading on the left |
| `alternating` | Two to four large features with their own image |
| `bento` | Items of differing importance, in mixed card sizes |
| `grid` | Six or more small, equal features |
| `tabbed` | Features that share one product view, using `../components/tabs.md` |

Section heading, then content `--space-10` to `--space-12` below. Card rules in `../components/card.md`.

A real picture of the feature beats an icon. Use as many items as there are.

**Phone:** one column. Images follow their text. Bento becomes a stack with the most important first.

**Avoid:** exactly three icon cards by habit. Two neighbouring feature sections with the same shape.
