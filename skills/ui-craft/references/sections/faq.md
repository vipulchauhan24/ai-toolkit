# FAQ

**Job:** answer what stops people.

| Variant | Use when |
|---|---|
| `accordion` | Five or more questions, using `../components/accordion.md` |
| `two-column` | Heading left, questions right |
| `open-list` | Up to four short answers, all visible |

Width `--container-narrow`, or a 4 + 8 split with the heading on the left. Real questions only. No marketing.

**Leave out** if no one is really asking anything.
