# Docs layout

**Job:** help people find an answer and get back to work.

**Layout from 1024px:** sidebar of 240 to 280px, content in `--prose`, on-page contents of 200 to 240px from 1280px. Each scrolls on its own. Header includes search.

- The sidebar is grouped, with the current page marked.
- Previous and next links at the end.
- Each heading can be linked directly.

**Phone:** the sidebar opens from a menu button, and contents collapse at the top.

Writing is covered in `../copy/copy-blog.md`.
