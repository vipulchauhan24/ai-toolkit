# Gallery

**Job:** let pictures do the work.

| Variant | Use when |
|---|---|
| `grid` | One aspect ratio, even grid |
| `mosaic` | Mixed sizes, planned so edges line up |
| `full-bleed` | A few very strong images, one per screen |

Use real images, each with alt text. Gap `--space-2` to `--grid-gap`. Serve responsive sizes, lazy-load below the fold, and reserve the space to avoid a jump.

**Phone:** one or two columns.

**Avoid:** images repeated. A lightbox as the only way of seeing the image at a usable size.
