# Testimonials

**Job:** let other people make the claim.

| Variant | Use when |
|---|---|
| `single-large` | One excellent quote |
| `two-column` | Two to six quotes of differing length |
| `with-result` | A quote beside a named result |

Uses `../components/testimonial.md`.

**Leave out** without real quotes.

**Avoid:** a rotating slider. Star ratings without a source.
