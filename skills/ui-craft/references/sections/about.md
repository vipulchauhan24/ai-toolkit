# About

**Job:** show there are real people, and why they do this.

| Variant | Use when |
|---|---|
| `text-portrait` | A person: short text and a real photo in a 7 + 5 split |
| `text-only` | No photo: text in `--prose` |
| `team` | Several people: grid of real names, photos and roles |

Keep it short. Facts over adjectives.

**Leave out** if there's nothing true to say.
