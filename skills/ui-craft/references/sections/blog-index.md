# Blog index

**Job:** help people find something worth reading.

| Variant | Use when |
|---|---|
| `list` | Text-first: title, one line, date. Rows split by 1px lines |
| `featured` | One lead post, then a list |
| `grid` | Real images on every post |

Width `--container-narrow` for lists. Show dates in one format. Add topics only if there are enough posts to fill them.

**Phone:** one column.
