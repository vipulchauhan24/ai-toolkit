# Projects

**Job:** show the best work, three to five items, best first.

| Variant | Use when |
|---|---|
| `list-rows` | No images: name, one-line problem and result, tags, link. Rows split by 1px lines |
| `feature-first` | One lead project, large, with others smaller |
| `image-grid` | Real images for each, in two columns with one aspect ratio |
| `alternating` | Two or three projects with strong images |

Each item names the problem and the result. Tags use `--text-xs` and name only what matters.

**Leave out** the section if there's no real project. Never show "Coming soon".

**Phone:** one column.
