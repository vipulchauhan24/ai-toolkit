# Proof and stats

**Job:** show evidence near the claim it supports.

| Variant | Use when |
|---|---|
| `sentence` | One or two numbers read best in a line of text |
| `row` | Two to four related, real figures |
| `divided` | Figures in one band, split by 1px lines |
| `with-source` | A number that needs its context beside it |

Uses `../components/stat.md`. Section padding can be small, or the row can sit straight under the hero.

**Leave out** if there are no real numbers.

**Phone:** two columns, or a list.

**Avoid:** round, unsourced numbers. A stat strip as a habit.
